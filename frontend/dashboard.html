🎯 How it Works

The ML model analyzes 6 transaction features (amount, hour, login attempts, response time, transaction frequency, and location changes) to identify suspicious patterns. It learns from normal transaction behavior to detect anomalies.

📊 Feature Analysis

Amount: Transaction value in ₹ | Hour: Time of transaction (0-23) | Login Attempts: Number of login tries | Response Time: Server response in ms | Frequency: Daily transaction count | Location: Whether location changed

✅ What's Normal?

Normal transactions typically: Small to medium amounts (₹100-₹50K), daytime hours (6am-11pm), 1-2 login attempts, fast response times (100-500ms), moderate frequency, same location

⚠️ What's Anomalous?

Anomalous transactions typically: Large amounts (₹50K+), late night/early morning (0am-5am), many login attempts (5+), slow response (800ms+), high frequency, location changes
